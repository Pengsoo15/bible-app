# 🚀 Maintenance & Updates Cheat Sheet

## To Update Your Live Site
Run these commands in your terminal whenever you want to push your local changes to the web:

```powershell
git add .
git commit -m "Describe what you changed here"
git push
```

## Adding New Secrets
If you add a new variable to your `.env` file (like another API key):
1. Go to [Vercel Dashboard](https://vercel.com/dashboard)
2. **Settings** -> **Environment Variables**
3. Add the new Key and Value.
